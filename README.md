# Data Structures in C++

A comprehensive collection of custom implementations of data structures in C++. This repository is designed for learning, testing, and professional reference. All data structures are implemented from scratch without external dependencies.

## Project Structure

```
DataStructure/
├── include/          # Header files for each data structure
│   ├── linear/       # Linear structures (Array, Linked List, Stack, Queue)
│   └── utils/        # Sample data, helpers
├── test/         # Example code to test each data structure
│   ├── array_test.hpp
│   └── ...
├── src/              # Main program to run examples
│   └── main.cpp
├── CMakeLists.txt
└── README.md
```
---
## Linear Data Structures

Sequential structures where elements are stored in a specific order.
- Arrays: Static Array (Fixed-size), Dynamic Array (Resizable).
